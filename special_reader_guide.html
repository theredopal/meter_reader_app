Special Reader: planning and day-of guide

Use this checklist to turn the day's Bright Forms work into a reviewed route, then move through the reads while you are out.

Before route planning

  1. Open Bright Forms and filter by date. Choose the date you are preparing for and verify that the displayed jobs belong to that date. Date filtering is done in Bright Forms; this tool does not fetch or filter Bright Forms records.
  2. Open Special Reader and add the work. Start typing the addresses into the Urgent reads or Normal reads box, select the correct suggestion, then add it. Use Urgent only for reads that should receive priority. The tool can also import CSV/TXT files.

Important: Pasting addresses copies the address text only. It does not import meter values, customer records, or completion status from Bright Forms. Keep using the approved Bright Forms process for recording readings.

Plan, sort, and review

  1. Choose Auto-sort when you want a suggested ordering, then press Plan route. Address lookup needs a working internet connection and Google Maps configuration.
  2. Wait for the location/route result. Check that the mapped markers correspond to the addresses you expect. Investigate any location lookup failures; ambiguous or misspelled addresses may resolve to the wrong place.
  3. Review the order before leaving. Auto-sort is a geographic-distance heuristic that takes urgent priority into account; it is not a promise of the shortest driving time and does not account for live traffic, access restrictions, opening hours, or every real-world constraint.
  4. Make any adjustments as needed: drag a read to reorder it, use row controls, or select multiple reads and use Bulk adjust to move, reprioritize, or reverse them. Use Undo if a change was accidental. Re-plan to refresh the route after making changes.
  5. Confirm that the pending count and addresses match the work you intend to complete. Export a CSV backup if you want a portable copy.

Using it on the day

  1. Open the same browser and device where you prepared the list. The worklist is saved locally in that browser; it does not automatically sync to another device. Alternatively, you can downlaod the ordered list to your device, transfer it to the device which you intend to use on the day via email or a cloud service, and import it to the site on that device.
  2. Use the Current read panel to see the next unfinished address. Refer to the map and list as needed.
  3. After completing a job and recording it in Bright Forms as required, press Clear this read · Next address in the reader to mark it done and advance to the next address.
  4. If you accidentally clear a read, use the Undo control. If a job cannot be completed, leave it pending and adjust the order or priority as appropriate.
  5. At the end, check the remaining count against your Bright Forms worklist. Export the list if you need a record or backup; do not treat this tool as the system of record for meter readings.

Useful reminders

  • Addresses without a valid located position may not appear in the map route.
  • Changes are saved in browser local storage. Clearing browser data can remove the saved list; export a backup when needed.
  • Use the landing page to return to the tools, or open the Special Reader directly.
